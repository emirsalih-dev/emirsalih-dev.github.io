# emirsalih-dev.github.io

EESY Dev kullanıcı sayfası. İki işi var:

- **`app-ads.txt`** — AdMob tarayıcısı, Play mağaza kaydındaki "Web sitesi"
  alanının **alan adı kökünü** tarar. Sitenin kendisi proje sayfası
  (`/eesydev.github.io/`) alt yolunda durduğu için app-ads.txt oradan
  görünmüyordu; bu depo dosyayı kökte yayınlar.
- `index.html` — kökü tanıtım sitesine yönlendirir.
